# S1-08 — Store core: New(dsn), NewWithDB(db), Postgres -> sqlite fallback

## Deliverable

One struct holding every per-entity store, opened from a DSN, with the sqlite:// switch and the Postgres-unreachable fallback behavior OurWay ships.

## Exit criteria

- [x] store.New(":memory:") works for tests (sqlite path)
- [x] the DSN scheme selects the driver (`postgresql://`/`postgres://` -> Postgres, `sqlite://path`, `:memory:`, `file:...`); a dead Postgres is a fatal boot, never a silent sqlite swap (OurWay has no fallback to copy — its New() is Postgres-only)
- [x] every entity store is reachable from the Store struct

## Notes

Criterion 2 restated at review: OurWay has no Postgres->sqlite fallback to copy (its `New(dsn)` is Postgres-only, `store.go:88-100`), so the rule is the plan's DATABASE_URL contract — the DSN scheme selects the driver and a dead Postgres is a fatal boot, never a silent sqlite swap. nvrWay does exactly that (`openDB`: `sqlite://`, `:memory:`, `file:` prefix, else Postgres) and `TestOpenDBChoosesDriverFromScheme` asserts it; `TestEveryRepositoryIsWired` asserts every entity store is reachable. sqlite keeps one connection (an in-memory DB is per-connection).
