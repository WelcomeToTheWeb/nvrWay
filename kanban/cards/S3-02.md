## Notes

Slug IS the stream name — no mapping table (plan Key Design Decision).

**Observed** 2026-11-02, `go test ./go2rtc -count=1 -run Config` in golang:1.26:
`ok  	nvr/server/go2rtc	0.005s` — 20 `Config*` tests PASS, 47 in the package;
full `go test ./... -count=1` green, `go vet ./...` exit 0, `gofmt -l .` silent.

Decisions the rendering forced, recorded in `config.go`:

- **Streams are sorted by slug.** The file is rewritten on every camera write, so
  map-iteration order would turn "I added a camera" into a full-file shuffle and
  the diff could not answer "did my change land?". A test asserts two input
  orderings render identical bytes, and that the caller's rows are not reordered.
- **`username`/`password` are rendered into `api` when GO2RTC_USERNAME/PASSWORD are
  set.** go2rtc only checks a password it was given, so rendering the API with no
  credentials makes the pair in `.env` a knob with no effect and the sidecar's
  "authenticated" API open to the network. Golden bytes cover this case.
- **A zero frame rate is refused, not rendered.** `GO2RTC_MJPEG_FPS=0` is a legal
  read (`config_test.go` asserts an explicit 0 stays 0) and `raw=-r 0` is a stream
  with no frames: the tap would open, produce nothing, and detection would
  silently never run. Same for width/height.
- **Sources are always double-quoted** (`strconv.Quote`): a source URI is dense
  with YAML structure (`:`, `#`, `*`, `&`, spaces). A test round-trips a URI
  containing a quote, a space and a `#`.
- `streams: {}` is the empty render — the shape go2rtc's loader accepts, asserted
  by parsing it back.
