# S9-03 — Dockerfile.web + nginx.conf: vite build -> nginx proxying /api and /ws

## Deliverable

OurWay's pattern: build stage then nginx:1.27-alpine serving dist, proxying /api
and /ws to server:8080, with proxy_buffering off + proxy_request_buffering off
on the clip route.

## Exit criteria

- [x] clip route streams (no buffering) and WS upgrade headers set
- [x] SPA fallback to index.html for the router's deep links

## Verification

`docker build -f docker/Dockerfile.web -t nvr-web:probe .`

## Observed

**Observed** 2026-11-06 — `docker build -f docker/Dockerfile.web -t nvr-web:probe .`:
exit 0 (npm ci + vite build + nginx:1.27-alpine, runs as `nginx:nginx`, listens
8080; compose publishes 3000:8080 — settled here, wired by S9-04). Probe stack:
postgres + `server` (nvr-server:probe) + `web` (nvr-web:probe) on one network.

- **SPA fallback**: `GET /cameras/c1` → `200 text/html` with `<div id="root">`.
- **API proxy**: `POST /api/auth/login` through nginx → real access token (432 chars).
- **WS upgrade**: handshake with the real token through nginx → `HTTP/1.1 101
  Switching Protocols` + `Sec-Websocket-Accept`. (This probe is what caught P-12:
  the production server had never mounted `/ws` at all — the hub was never
  constructed. Fixed and pinned by `server/router_test.go` before this card closed.)
- **Clip route streams**: a fake upstream that sends the first chunk then sleeps
  3s; through nginx `time_starttransfer=0.0015s`, `time_total=3.002s` — the body
  is streamed, not buffered.

The skeleton's nginx.conf needed no changes; the only edit is the Dockerfile
comment settling the published port.

Mutation evidence — each break kills its criterion, restore re-green (`diff` clean):

| Mutation | Observed failure |
| --- | --- |
| drop `proxy_buffering off` + `proxy_request_buffering off` from the clip route | TTFB 0.0015s → **3.0015s** — the clip stalls until the body is complete |

| `try_files $uri $uri/ /index.html` → `=404` | deep link `/cameras/c1` → **404** |
