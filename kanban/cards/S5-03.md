# S5-03 — model.py: letterbox preprocess, YOLOv8 decode, NMS, class sets

## Deliverable

InferenceSession(path, providers); preprocess = letterbox 640 (pad 114), BGR->RGB, /255, CHW, batch, float32; postprocess handles [1,84,8400] -> xywh -> corners -> clip -> argmax class -> conf/area filters -> numpy NMS (IoU 0.45, max 100).

## Exit criteria

- [x] CLASS_NAMES is the 80-name COCO list verbatim; IGNORED_CLASSES drops all but person, bicycle, car, motorcycle, bus, truck, dog, cat, bear
- [x] min_confidence and min_area_ratio filters applied
- [x] letterbox round-trip maps a padded-edge box back inside the frame
- [x] providers list comes from DET_PROVIDERS, comma-split

## Verification

`cd detector && python3 -m pytest tests/test_decode.py -q`

**Observed** 2026-11-03, in `nvr-detector:dev` (the host has no pytest): `24 passed
in 0.10s` — eight of those tests are S5-02's mjpeg half, sixteen are this card's.
The slow smoke against the real weights is `2 passed` (card S5-11).

- **The 80 names are checked against a list written out in the test**, not against
  the module: `COCO_NAMES` in `test_decode.py` is transcribed from the COCO/YOLO
  order, and `assert CLASS_NAMES == tuple(COCO_NAMES)` is what keeps `"tv"`,
  `"hair drier"` and `"cell phone"` exactly as the weights emit them. `IGNORED_CLASSES`
  is derived as the complement, so it cannot drift, and the test asserts the three
  names that would open an event every time someone turned a television on.
- **The decode is tested on a planted `[1, 84, 8400]` tensor**, one anchor per row:
  class 0 at conf 0.9, centre (120, 100), size (40, 100) comes back as
  `(100, 50, 140, 150)`. A traffic light at conf 0.99 decodes to nothing.
- **NMS is pinned at both edges**: `(0,0,100,100)` against `(20,0,120,100)` is IoU
  8000/12000 = 0.667 → one box, the conf 0.90 one; `(0,0,100,100)` against
  `(60,0,160,100)` is 4000/16000 = 0.25 → two boxes. `NMS_IOU_THRESHOLD == 0.45` is
  asserted as a constant so a silent retune fails.
- **The letterbox round-trip is the 1280×720 case**: scale 0.5, 140 rows of padding,
  a model-space box spanning y 130..200 maps to y −20..120 and must clip to
  `y1 == 0, y2 == 120` with x 600..680. The pad value and the channel order are
  asserted too — the top row is `114/255` in every channel, and a BGR frame whose
  channel 2 is 255 arrives as red channel 1.0 (cv2 hands BGR, the weights were
  trained on RGB, and getting that backwards moves no box, which is why it needs its
  own test).
- **`providers_from_env` is comma-split with blanks dropped**, and an unset
  `DET_PROVIDERS` is `["CPUExecutionProvider"]`.

## Notes

Detection-eligible set is a decision, not a filter knob.

- **A CPU build of onnxruntime does not raise for a missing GPU provider — it warns
  and quietly runs CPU.** Measured: `InferenceSession(path, providers=["CUDAExecution
  Provider"])` on this build answers `UserWarning: Specified provider
  'CUDAExecutionProvider' is not in available provider names. Available providers:
  'AzureExecutionProvider, CPUExecutionProvider'` and loads anyway. So the fallback
  cannot be written as `try/except`; `_open` now checks the request against
  `get_available_providers()` **before** opening and logs the substitution:
  `model: providers CUDAExecutionProvider are not available in this onnxruntime build
  (it has: AzureExecutionProvider, CPUExecutionProvider); using CPUExecutionProvider —
  the CUDA overlay is opt-in (docker-compose.gpu.yml) and needs nvidia-container-toolkit
  on the host`. `YoloOnnx.providers` reports what the session **got**, and `__main__`
  logs it after the load, so a GPU overlay that failed to install looks like what it
  is instead of like a success. The `try/except` is still there for a provider that
  advertises itself and then fails to load.
- **`postprocess` is a module function with the method as a thin delegate**, so the
  suite can hand it a planted tensor without opening a session — and the session path
  is covered separately by `test_the_session_runs_the_whole_chain_over_a_real_onnx_model`,
  which writes a two-kilobyte model with `onnx` and reads a box back out of
  onnxruntime. A model whose output is not a YOLOv8 head raises
  `unexpected model output shape …, want [anchors, 84]` rather than returning boxes it
  invented.
- **The area floor is applied after the clip**, not before: a box that loses half its
  height to the frame edge is the small box the filter is there to catch.
