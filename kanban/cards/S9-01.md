# S9-01 — Dockerfile.server: alpine builder + runtime with ffmpeg, non-root, healthcheck

## Deliverable

golang:1.26-alpine builder (git, ca-certificates, tzdata; layer-cached go mod
download; CGO_ENABLED=0 build with -ldflags stamping config.Version/config.GitCommit),
alpine:3.20 runtime with ffmpeg, non-root nvr user, EXPOSE 8080, wget --spider /health.

## Exit criteria

- [x] image builds; version line in the boot log names the stamped version and commit
- [x] ffmpeg present at runtime (recorder and clip builder shell out to it)
- [x] runs non-root and the healthcheck passes

## Verification

`docker build -f docker/Dockerfile.server -t nvr-server:probe .`

## Notes

Copy OurWay's Dockerfile.server structure; the ffmpeg line is the nvrWay delta.

## Observed

**Observed** 2026-11-06 — `docker build -f docker/Dockerfile.server --build-arg
VERSION=0.9.0-s901 --build-arg GIT_COMMIT=f342475 -t nvr-server:probe .`: exit 0.
Against a `postgres:16-alpine` (compose's pin) on a probe network: boot log
`Starting nvrWay server 0.9.0-s901 (f342475) on :8080`; `GET /health` →
`{"git_commit":"f342475","status":"ok","version":"0.9.0-s901"}`; `docker exec … id`
→ `uid=100(nvr)`; `ffmpeg -version` → 6.1.1; `docker inspect .State.Health` →
`healthy`.

Two findings, both durable:

- **The container is Postgres-only, on purpose.** `CGO_ENABLED=0` (the card's
  instruction) compiles go-sqlite3 to its stub: a sqlite `DATABASE_URL` fails at
  boot with "Binary was compiled with 'CGO_ENABLED=0'". sqlite is the host-dev
  path; the image's database is the compose postgres. Kept CGO_ENABLED=0 —
  a CGO/musl build for an in-container sqlite was rejected (static binary,
  no libc surface; the stack always ships postgres).
- **`.dockerignore` added.** Without it the build context shipped 212 MB of
  `web/node_modules` to the daemon. It now excludes node_modules, `.git`,
  runtime state, and the model weights (the detector image exports ONNX at
  build time, S5-12).

Mutation evidence — each break kills its criterion, restore re-green (`diff` clean):

| Mutation | Observed failure |
| --- | --- |
| drop `ffmpeg` from the runtime `apk add` | `exec: "ffmpeg": executable file not found in $PATH` |
| `USER root` | `docker exec id` → `uid=0(root)` |
| ldflags stamp `config.Versionn` (typo'd symbol) | boot log `Starting nvrWay server dev (unknown)` — Go ignores `-X` on a missing symbol **silently**, so the version line is the only guard the stamp has |
