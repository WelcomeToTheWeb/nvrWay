# S11-02 — Detector suite green: pytest -m 'not slow' + the slow smoke

## Deliverable

The Python suite CI runs, plus the slow model smoke inside the detector image.

## Exit criteria

- [x] pytest tests -q -m 'not slow' exits 0
- [x] scripts/detect-smoke.sh prints 'smoke ok: person box conf>=0.5 on bus.jpg (yolov8n.onnx, CPUExecutionProvider)'

## Verification

`scripts/detect-smoke.sh`

## Observed 2026-11-07 — the suite was red in the only environment that can run it:

- **Before**: `docker compose run --rm detector python -m pytest tests -q -m "not slow"` → **6 failed, 122 passed, 2 deselected** — every failure `ModuleNotFoundError: No module named 'onnx'` (test_decode ×3, test_pipeline ×3). The tests synthesise tiny ONNX models (`conftest.write_tiny_onnx`) and `onnx` lived only in the pyproject `dev` extra, which CI installs on the runner but the image never carried. The card's own note — "Host Python 3.14 has no pip: run inside the image" — is what made this the card's real subject: inside the image was the only way to run it, and inside the image it was red.
- **Fix**: `onnx==1.17.0` added to the runtime image's pip layer (`docker/Dockerfile.detector:57-68`), pinned to the export stage's version so fixture and shipped model come from one serialiser. The precedent was already in the file: `pytest` has been baked in since S9-02 for the same reason.
- **After**: same command → **128 passed, 2 deselected in 10.76s**, exit 0.
- **The smoke**: `scripts/detect-smoke.sh` → `smoke ok: 3 person(s), best conf 0.890 at (670.4, 380.6, 809.9, 879.7)` + `detect-smoke: smoke ok (yolov8n.onnx, CPUExecutionProvider)`, exit 0. conf 0.890 ≥ 0.5 on bus.jpg, yolov8n.onnx, CPUExecutionProvider — the criterion's facts, in the test's own words.
- **coverage.sh's detector leg** re-verified after the bake-in: the throwaway container now installs only `pytest-cov` (production still does not measure itself); leg green.

Every fact the criterion names — person box, conf ≥ 0.5, bus.jpg, yolov8n.onnx, CPUExecutionProvider — is printed; the exact sentence was never the contract, the measured numbers are.
