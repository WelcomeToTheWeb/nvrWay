# S10-01 — testdata/fixtures.json + scripts/fetch-fixture.sh (pinned assets, recorded hashes)

## Deliverable

Pin bus.jpg (137 419 bytes, CC-BY-4.0) and yolov8n.pt (6 549 796 bytes, AGPL-3.0)
with URL, bytes, sha256, license; the fetcher downloads, verifies byte counts
and writes sha256s on first run. Files are not committed.

## Exit criteria

- [x] byte counts verified against the pins, fetch fails loudly on a mismatch
- [x] fixtures.json carries license + attribution
- [x] the three asset files stay out of git (gitignore already lists them)

## Verification

`scripts/fetch-fixture.sh && cat testdata/fixtures.json`

## Observed

**Observed** 2026-11-06 — `scripts/fetch-fixture.sh`:
`bus.jpg: already present, verified (137419 bytes)` /
`yolov8n.pt: verified (6549796 bytes, sha256 f59b3d833e2f…)` — the downloaded
.pt hashes exactly to the pin recorded 2026-11-03. Mutation: appended one byte
to bus.jpg → `present but does NOT match the pin (bytes 137420/137419, sha
a1ec258bf077/c02019c4979c) — refetching`, refetched and verified; unknown
target → rc=1 naming the pinned set. `git ls-files testdata/` = fixtures.json
+ segments/.gitkeep only — the three assets are on disk, out of git.

The manifest was written by S5-12 and needed no change: `assets[]` (fetched)
is separate from `exported[]` (built by the image — the fetcher must not
download yolov8n.onnx), and the .onnx entry says out loud that its hash is a
record, not an enforceable pin (AutoUpdate's unpinned onnxslim changes the
bytes; the smoke test is the real gate). The fetcher verifies bytes first,
then sha256 — a byte-count match with a hash mismatch is a swapped file, a
hash without bytes is a truncated transfer; both print both numbers. A
manifest entry with no sha256 gets it recorded on first verified download —
the path the existing pins were born through.

## Notes

The only network-dependent step in the acceptance path; it runs once per
machine. The fast detector suite never needs these files (only the slow smoke
does), so CI's `pytest -m "not slow"` runs without fetching.
