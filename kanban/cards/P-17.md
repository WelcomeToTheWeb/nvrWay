# P-17 — the harness the pages use was born in client.test.ts and never moved

## The finding

`src/test/axiosHarness.ts` (S8-11) is the shared real-adapter harness the page
suites ride, but its two sources of truth — `api/client.test.ts` (S8-02) and
`auth/context.test.tsx` (S8-03) — kept their own local copies of it. Three
copies of the adapter means a fix to one (the `attempt` counter, the
`AxiosError` shape) silently does not reach the others, and the shared file's
claim to be *the* harness was only true of the page tests.

## The fix

Both suites now import `axiosHarness`/`UNAUTHORIZED`/`Call`/`Script` from
`src/test/axiosHarness.ts`. `client.test.ts` drops its local copy wholesale
(the signatures matched exactly). `context.test.tsx` keeps a three-line local
`harness()` that wires `client.defaults.adapter` and returns the call log —
its tests script calls without caring about bearer or attempt count, and the
wrapper keeps every call site unchanged. One assertion got stronger on the
way: the logout test's `toEqual` now pins `bearer: 'Bearer a-1'` too, because
the shared `Call` records the bearer the local one did not — logout is a
session call and the test now proves the token rides on it.

## Exit criteria

- [x] no local adapter copies left under `src/` — the only `adapter` builders
      are the shared harness and one deliberate raw adapter in
      `context.test.tsx` (the network-down case, which must throw
      `ERR_NETWORK`, not a scripted status)
- [x] `tsc --noEmit` clean; vitest 198/198, three consecutive full runs
- [x] the logout assertion strengthened, not weakened, by the shared `Call`

## Verification

**Observed 2026-11-07:** `npx tsc --noEmit` clean; `npx vitest run` 198/198
three times in a row. `grep -rL axiosHarness` over the test files leaves only
`live/go2rtc.test.ts` and `stores/realtime.test.ts` — both WS suites, no
axios in the path under test, correctly out of scope.

### Mutation evidence

| Mutation | Expected | Observed |
|---|---|---|
| drop `bearer: 'Bearer a-1'` from the logout expectation | the strengthened assertion fails against the shared harness's `Call` | confirmed during migration: the pre-migration expectation (no bearer) failed exactly there — that is how the strengthening was found, not invented |
| shared harness `UNAUTHORIZED` status → 403 | the refresh-path tests stop refreshing | not run: the shared file is untouched by this card; its own behavior is S8-11's evidence |
