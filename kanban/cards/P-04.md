# P-04 — Keep the board honest (move cards, record evidence)

## Deliverable

The board only earns its keep if cards move with the work: move the card before starting, to Review when the code is in, to Done when the card's verification command exits 0.

## Exit criteria

- [x] at most 2 cards In Progress at any time
- [x] no card reaches Done without its verification command's output quoted in the commit message
- [x] KANBAN.md regenerated with python3 kanban/board.py in the same commit as the card move

## Verification

`python3 kanban/board.py && git diff --stat KANBAN.md`

## Notes

Enforced, not just written: `kanban/pre-commit.sh` is installed in `.git/hooks/pre-commit` and ran on every commit since — `a1753dc` (P-01 close) printed `110 cards, 0 violation(s)` twice and staged the regenerated KANBAN.md in that same commit. The baseline commit quotes the test output, P-01's commit quotes `git remote -v` + `gh repo view`, and this commit quotes the suite. In Progress has stayed at or under 2 throughout.
