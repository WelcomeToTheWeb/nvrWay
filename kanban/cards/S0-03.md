Six services — `docker compose -f docker/docker-compose.yml config --services`
prints `go2rtc postgres server detector web`, plus one commented
`# minio:` block (`grep -c '^  # minio:'` → 1), the way OurWay comments its
agent service. Prod has **no** build sections (`grep -c "build:"` → 0) and
names the three published images:
`ghcr.io/welcometotheweb/nvr/{server,detector,web}:latest`.

`GO2RTC_PUBLIC_URL` is required in prod by compose interpolation, observed:

```
error while interpolating services.server.environment.GO2RTC_PUBLIC_URL:
required variable GO2RTC_PUBLIC_URL is missing a value: GO2RTC_PUBLIC_URL is
required — the address the console's browser can reach
```

The `docker/.gitkeep` from S0-01 is deleted in this commit, as that card
recorded.

**Two deviations, both deliberate:**

- **Console port is `3000:8080` in both composes.** OurWay's dev compose
  publishes `3000:80` while its nginx listens on 8080 (prod uses `3000:8080`),
  so the dev mapping does not reach the listener. nvrWay's nginx listens 8080
  (unprivileged user) and both composes publish 8080, so README's "console on
  :3000" is true from the start. Check it against `docker/nginx.conf`.
- No `version:` key in either compose: Compose v5 warns on it, and a
  validation that prints warnings is a validation nobody runs.
